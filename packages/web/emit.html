Structured light — projector emitter

This window is the projectors. Put it full-screen on the framebuffer that drives them, tell it what the rig is, and it plays the calibration sequence into one projector’s raster at a time. Nothing is installed and nothing on the display machine is changed.

The rig

The sequence

Frames leave here encoded for a display gamma of 2.2 — PARAMETERS.md §3.2’s nominal. The Gray planes do not care, being black or white either way; the phase steps are sinusoids in emitted light and would be biased by a projector whose transfer is far from that. §3.2 classes the per-channel exponents as unmeasured and notes real projectors diverge 0.1–0.3 between channels, so this is an assumption rather than a measurement, and nothing here can check it for you.

Read a capture back

After shooting, bring the photographs here with the plan file you saved above. This decodes them and says what the capture was worth — how many correspondences survived, out of how many camera pixels, and which projectors nothing reached. It does not compute a pose: that needs each camera’s intrinsics, which this page does not have and cannot derive.

Your files are read through a canvas, which converts whatever colour profile they carry into sRGB before this page sees a single pixel. So the transfer is not a setting: these bytes are sRGB whatever the camera wrote, and telling the decoder otherwise would leave every correspondence in place and move it about thirteen times further from the truth. Shoot JPEG or PNG. A RAW file the browser cannot decode is refused rather than guessed at.

Before you photograph anything, step to each projector’s white frame and check that the projector that lights up is the one the panel names. If it is not, this display’s quadrant order differs from the config’s, and every frame after that would be filed under the wrong projector.

This panel is on the sphere. Arm before you open the shutter.

If you opened this from a file or a USB stick — a file:// address in the bar — that is the cause. Browsers refuse to load a page’s modules from a file origin, and the refusal is silent. Copying the folder does not help; it has to come off an http:// address. Any static server will do, on this machine or a laptop you can reach: from a checkout, npm run app serves it at http://localhost:8174/emit.html.

If the address already starts with http, then dist/web/web/emit.js did not arrive beside this page. Open the browser console — a 404 names the file it wanted.
